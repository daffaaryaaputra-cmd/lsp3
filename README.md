# LSP-P3 TKJ

Dokumentasi konfigurasi Ubuntu Server untuk praktik LSP-P3.

## Isi

File [KONFIGURASI-LSP-P3.txt](./KONFIGURASI-LSP-P3.txt) berisi konfigurasi dan langkah-langkah yang digunakan, meliputi:

- Netplan dan SSH
- MariaDB dan database
- Apache2 dan PHP
- phpMyAdmin
- VirtualHost dan landing page
- DNS BIND9
- Firewall UFW
- Pengujian akhir

> Catatan: File konfigurasi disimpan mengikuti isi sumber yang diberikan.
